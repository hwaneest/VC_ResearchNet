# People Lab ResearchNet

우리 연구실(석사·박사 재학생 및 졸업생)의 연구를 한곳에 모아, 구성원 누구나
서로의 연구를 **검색·탐색**하고 **연구자 네트워크**를 볼 수 있게 하는 정적 웹사이트입니다.

예) "박사 졸업생 중 **텍스트 마이닝** 연구를 한 분과 그 논문은?", "**리더십** 주제 논문과 저자는?"
같은 질문에 검색·필터로 바로 답할 수 있습니다.

## 구성 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 페이지 뼈대 |
| `styles.css` | 디자인 (흑백 계열) |
| `app.js` | 검색·필터·네트워크 로직 (외부 라이브러리 없음) |
| **`data.js`** | **논문·저자 데이터 — 여기만 고치면 됩니다** |

## 실행 방법

### 1) 바로 열어보기 (혼자 확인용)
`index.html`을 더블클릭 — 대부분의 기능이 동작합니다.
> 일부 브라우저는 로컬 파일 보안정책으로 `data.js` 로딩을 막을 수 있습니다.
> 그럴 땐 아래 로컬 서버 방식을 쓰세요.

### 2) 로컬 서버로 열기 (권장)
이 폴더에서:
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.

### 3) 웹에 올려 팀과 공유하기
정적 파일이라 아래 어디에 올려도 그대로 동작합니다.
- **GitHub Pages** (무료, 사내 공유에 무난) — 이 폴더를 리포지토리로 push 후 Pages 활성화
- Netlify / Vercel — 폴더 드래그&드롭 배포
- 사내 웹서버의 정적 디렉터리에 복사

## 데이터 추가/수정 (`data.js`)

`data.js` 상단 주석에 각 항목 설명이 있습니다. 요약:

**저자(구성원)** — `authors` 배열
```js
{
  id: "hong_gd",              // 고유 id — <성>_<이름 이니셜>. 논문에서 이 값을 참조
  name: "홍길동",
  nameEn: "Gildong Hong",     // 선택
  degree: "PhD",              // "PhD"(박사) | "MS"(석사)
  status: "graduated",        // "graduated"(졸업) | "completed"(수료)
  year: 2020,                 // 졸업/수료 연도 (재학 중이면 null)
  current: "○○대학교 조교수",  // 현재 소속/직함
  interests: ["리더십", "텍스트 마이닝"],
}
```

**논문** — `papers` 배열
```js
{
  id: "p20",
  title: "논문 제목",
  authorIds: ["hong_gd", "이몽룡"],   // 저자 (순서대로). 등록된 사람은 id, 미등록은 이름 문자열
  extAuthors: ["J. Smith"],          // 뒤에 덧붙일 외부 공저자 (선택)
  venue: "인사조직연구",
  year: 2024,
  type: "journal",                   // "journal"(학술지) | "conference"(학회) | "thesis"(학위논문)
  methods: ["텍스트 마이닝"],          // 방법론 태그
  topics: ["리더십"],                 // 주제 태그
  doi: "https://doi.org/...",        // 있으면 제목이 링크가 됨 (선택)
  abstract: "한 줄 요약(선택)",
}
```

### 팁
- `authorIds`에 `authors`의 `id`와 **정확히 일치**하는 값을 넣으면 저자 연결·네트워크가 그려집니다.
  등록되지 않은 사람은 **이름을 그대로** 적으세요 — 저자명은 순서대로 표시되지만 클릭은 되지 않고
  네트워크에도 나타나지 않습니다. 나중에 `authors`에 추가하고 id로 바꾸면 자동으로 연결됩니다.
- 태그(`methods`/`topics`)는 **같은 개념은 같은 문자열로 통일**하세요.
  (예: "텍스트마이닝"과 "텍스트 마이닝"을 섞지 말고 하나로) → 필터가 깔끔해집니다.
- 논문을 추가하면 방법론·주제 필터 드롭다운은 **자동으로** 채워집니다.

## 기능 요약
- **논문 뷰**: 제목·저자·게재지·방법론·주제 태그. 검색어(제목/저자/방법론/주제/초록)로 즉시 필터. 최신/제목순 정렬.
- **연구자 뷰**: 구성원 카드(학위·졸업/수료·연도·현 소속·관심사·논문 수). 클릭 시 상세.
- **네트워크 뷰**: 공저 관계 그래프. 노드=연구자(지도교수·박사=검정 / 석사·학사=흰색, 크기=논문 수), 선=공저(굵을수록 공저 多).
  드래그로 이동, 클릭으로 상세, 위 검색·필터로 특정 방법론/주제 연구자 강조.
- 태그·저자 이름을 클릭하면 바로 해당 조건으로 필터링됩니다.
